# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Default branch (`main`) | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories by clicking **"Report a vulnerability"** on this repository.

**Do not open public issues for security reports.**

**Do not mention or speculate about any specific vulnerability.**

## Response Targets

*   **Acknowledgement:** within 5 business days
*   **Status update:** within 14 days
*   **Coordinated disclosure:** Yes
*   **Bug bounty:** No (we do not offer a bug bounty at this time)
